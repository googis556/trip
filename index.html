Firebase 설정이 필요해요

이 앱은 여행 일정표 전용 Firebase 프로젝트에 회원 정보와 일정을 저장해요. 아래 순서대로 한 번만 설정하면 됩니다.

  1. Firebase 콘솔에서 새 프로젝트를 만들어요.
  2. Authentication → 로그인 방법 → 이메일/비밀번호를 사용 설정해요.
  3. Firestore Database를 만들고, 규칙 탭에 firestore.rules 내용을 붙여넣어 게시해요.
  4. 프로젝트 설정 → 웹 앱 추가 → 나오는 설정값을 firebase-config.js에 붙여넣어요.

함께 짜는 여행 일정표

시간표에서 시작 시간부터 끝 시간까지 드래그하면 일정이 들어가요. 링크를 보내면 함께 가는 사람과 실시간으로 같이 편집하고, 완성된 일정은 이미지나 PDF로 공유할 수 있어요.

개인 이름이나 단체 이름으로 가입하세요. 공유받은 링크가 있으면 로그인하지 않아도 일정을 볼 수 있어요.
